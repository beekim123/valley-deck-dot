# 《一副山谷》0.1.0 试玩候选

## 这是哪一版

第一卷「河湾」：拖动村民到地点，先看预览再分派，入夜结算，最后让老水磨重新转起来。没有战斗、食物维持或失败状态。第二卷只展示未开启提示。

## 运行

- macOS 候选 ZIP：解压后打开其中的《一副山谷》应用。包含 Apple Silicon 与 Intel 两架构。尚未在真实 Mac 验证，未公证；若系统拦截，请不要关闭系统保护或移除隔离标记，可选择用源码在你自己的 Godot 中运行。
- 源码：用 Godot **4.7.2** 导入 `godot/project.godot`，按 F5。素材和数据副本已包含，不必先安装 Node 才能玩。
- 重建与测试：Node 22.13+，`npm ci`，设置 `GODOT_BIN` 后执行 `npm run build`、`npm run check`、`npm run sim`。

## 操作

拖人物到地点 → 查看用途/费用/结果 → 选择用途。右键或拖回手牌撤销；资源会退还。点入夜播放结算，可跳过或在设置切简短。长卷可拖动和用箭头看；空格/回车翻页，Esc 打开菜单。首日先免费焐醒托比和米拉。

每天清晨自动存档；退出重进回到当天清晨，尚未结算的分派不保留。资源耗尽仍有免费的拾柴、捡石、晒太阳来源。

## 请重点反馈

1. 能否在你的 Mac 正常启动？机器芯片、系统版本是什么？
2. 声音是否舒适、过响或刺耳？当前云端仅完成数值和播放检查，没有主观试听。
3. 拖放预览是否清楚？有没有字挤出、点不到或卡住？
4. 是否有一天觉得无聊？用了几天通关、实际玩了多久？
5. 最想保留/最想改的一件事是什么？

这是候选版，不是已完成干净 Mac 验收的正式 `demo-1`。原始随机测试失败与后来修订的验收标准都保存在 `docs/plan/acceptance-v2.md` 和 `artifacts/reports/`，没有隐去。

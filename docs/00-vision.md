# 00 · 愿景与 Demo 范围

## 1 一句话

**《一副山谷》**（暂定名，英文名待定）：一场长冬把晴溪谷连同村民冻进了一副牌。春天终于来了，你回到谷里，把牌一张张摆上桌：把村民放到地方上去，焐化冰封、翻开新地方、唤醒冻住的人，看着桌子上方那幅雪景长卷一段段变回春天。

> 整座山谷冻在一副牌里。春天来了，把它一张张焐暖。

## 2 相对原方案「外婆的牌」的调整

| 原方案 | 现在 | 理由 |
|---|---|---|
| 外婆封牌、孙辈回乡 | 守谷人「柏翁」封牌，主角是他的学徒「阿暖」 | 竞品 Carto 是"女孩和奶奶 + 地图块 + 温馨无敌人"，祖孙结构太像。师徒关系保留了"长辈留下的谜" |
| 灰潮、灰雾 | **长冬、霜封**。地点牌从冰封到解冻再到回春 | 冬去春来的视觉辨识度更高。"唤醒"和"春醒"意思天然接上。也避开了 Chicory 的"给褪色的世界重新上色"和 Loop Hero 的"被遗忘的世界" |
| 灵光 | **暖意** | 用暖意焐醒冻住的人，和主题一致 |
| 资源是要拖动的牌 | 资源是桌边的计数筹码 | 少一类要拖的东西，操作更简单 |
| 翻开的牌变成俯视地块，拼成地图 | 回春的地点进入桌子上方的**山谷长卷**：一幅横向侧视风景，醒来的村民在上面走动 | 用户要求不要俯视地图。长卷是看得见、一直在长的成果 |
| 主角只负责摆牌 | 阿暖自己也是一张人物牌，**只有阿暖会"焐"**（用暖意融化霜封、唤醒冻住的人） | 每天的分派多了一个关键决定：今天阿暖去焐谁 |
| 咒语牌（外婆留下） | 「冬眠诀」：柏翁留下的稀有一次性牌 | 同上 |
| 没有旁白人物 | 柏翁炉子里的火种「小烬」会说话，担任旁白与教学 | 炉石式旁白人物 |
| "某人去某地会发生新事件"没有具体机制 | **新鲜事**：人物和地点的第一次特殊组合。拖过去时用 ✦ 提示"会有新鲜事"，但不剧透内容 | 这是核心乐趣，需要一张内容表撑住；✦ 提示让玩家不用瞎猜 |
| 5 章，6–10 小时 | Demo 只做第一卷「河湾」，约 12 天 | 先验证核心玩法 |

核心玩法全部保留：按"天"推进的回合；把人物牌拖到地点牌上，拖动时预览、确认后执行；夜里结算，牌面小场景动起来；翻牌发现新地方；唤醒沉睡的人；事件牌带公开倒计时；没有战斗，没有失败。

## 3 设计支柱【定】

1. **每张牌背后都有人和故事**：卖点是"唤醒山谷里的人"，不是"摆地块让自己变强"。
2. **发现的惊喜**：翻开雾牌、某人第一次去某地发生的新鲜事、冻在冰里的人醒过来。
3. **没有失败，没有生存压力**：不用喂饱谁，没有实时倒计时；事件过期只会走向另一个温和的结果。
4. **先看后定**：拖动人物时，所有结果都先预览，确认后才执行，不让玩家猜设计者的心思。
5. **看得见山谷活过来**：牌面解冻、长卷回春、村民在长卷上走动，音乐随回春的地方变多而丰富起来。
6. **故事在牌桌上讲**（见 [04-storytelling.md](design/04-storytelling.md)）。

## 4 目标体验

| 时刻 | 玩家应该感到 |
|---|---|
| 第一天 | "托比去伐木，米拉去看看那张雾牌……阿暖呢？"三张牌三个决定，一分钟上手 |
| 拖到地点上看到 ✦ | "有新鲜事？让她去试试！" |
| 夜里结算 | 牌面上的小人动起来，一句话一个笑点 |
| 冻住的人醒来 | 冰壳裂开，老梅伸个懒腰："我的姜茶呢？凉了十年了吧。" |
| 一块地方回春 | 长卷上那一段从白变绿，有人在上面走：成就感 |
| 事件过期 | "哎呀，桥被水淹了"，三天后河滩上捡到一封漂来的信：坏事也有好的一面 |
| 水磨转起来 | 整卷长卷最后一段变成春天，配乐所有声部都响起来 |

基调：安静、温暖、有一点幽默，偶尔有一点寂寞。全年龄。

## 5 Demo 范围【定】

| 项 | 内容 |
|---|---|
| 章 | 只做第一卷「河湾」，目标"让老水磨重新转起来" |
| 时长 | 约 12 天（不设上限），30–45 分钟 |
| 内容量【建议】 | 地点牌 11 张；人物牌 5 张（另有磨坊一家在结尾醒来）；事件 6 个 + 访客 3 个；新鲜事 17 条；冬眠诀 2 张；柏翁笔记 3 页 |
| 资源 | 木、石、暖意，共 3 种 |
| 平台 | macOS 本机运行。Web 导出可选 |
| 操作 | 鼠标拖拽为主 |

**Demo 要回答的问题**（详见 [plan/playtest.md](plan/playtest.md)）：
1. 拖放加预览，能不能让玩家不去算最优解、轻松地玩？
2. 每天都有新鲜感吗？会不会出现"白过的一天"？
3. 没有战斗，用户还觉得好玩吗？
4. 长卷和唤醒能不能给出足够的成就感？

## 6 刻意不做【定】

原方案清单，原样保留：

- 战斗
- 食物维持
- 实时倒计时
- 复杂的合成表
- 超过 3 种资源

Demo 阶段额外不做：

- 第二卷及以后（只放一页上锁的预告）
- 自由摆放建筑、装修
- 显示好感度数值
- 多存档槽、成就

## 7 术语（玩家可见，最多 5 个）【定】

| 术语 | 含义 |
|---|---|
| 暖意 | 阿暖用来融化霜封、唤醒冻住的人 |
| 霜封 | 被冰封住的地点或人，要焐化才能用 |
| 事件 | 带倒计时的小任务，过期只会换一种结局 |
| 新鲜事 | 某个人第一次去某个地方会发生的特别的事，用 ✦ 提示 |
| 冬眠诀 | 柏翁留下的一次性牌，当天改写一条规则 |

木和石不算术语。"长卷""回春"在第一次出现时用一句话说明。

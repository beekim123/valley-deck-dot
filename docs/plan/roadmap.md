# 里程碑

按顺序做，不按日期。每个里程碑结束时，游戏都能从标题玩到当前进度的结尾。验收不通过就不进入下一个。

## D0 · 地基

目标：所有管线都通一遍，Godot 能启动。

- 按 [repository-layout.md](../tech/repository-layout.md) 建好全部目录、`.gitignore`、`package.json` 脚本。
- 美术：`palette.json`、`lib/png.mjs`、`lib/pixel.mjs`（含 `recolor`、`snowcap`、`dissolve`）、`tools/resources/art.mjs`；画 1 个字符画素材（托比头像）和 1 个程序素材（松林小场景，导出冬春两版）；build/verify/sheet 跑通。
- 声音：`synth.ts`、2 个音效（`sfx.card_drop`、`sfx.ice_crack`）、1 段 8 秒测试旋律；导出 WAV、`audio:check` 跑通。
- 内容：`content/registry.json` + 最小 `locations.json`；`content:check` 跑通。
- 同步：`npm run sync` / `sync:verify`。
- Godot：工程设置、AssetCatalog、AudioService、字体；标题画面显示文字和松林冬春两张图，点击切换并发声。
- 测试：无界面测试框架 + 1 个规则测试。

**验收**：`npm run check` 全部通过；标题画面截图（3 倍放大）文字清楚、像素不糊、冬春两版明显是同一个地方。

## D1 · 规则可玩（灰盒）

目标：用简单的代码画灰盒图，完整玩通第一卷，并用自动试玩证明不会卡死。

- 规则全部实现：地点四种状态、分派/预扣/撤销、预览、夜里结算、新鲜事、事件（完成/过期/暂停）、保底访客、冬眠诀、章节目标、回春与每日产出。
- 全部内容数据：11 个地点、5 个人物、17 条新鲜事、6 个事件 + 3 个访客、2 张冬眠诀。
- 牌桌界面（灰盒）：拖动、高亮、预览框、选择框、资源"现有 → 剩余"、事件牌、目标卡、一日小结。长卷先用色块表示每一段的冬/春。
- 唤醒、笔记、结尾先用纯文字页代替。
- 存档。
- 三种自动试玩策略与报告。

**验收**：
- 全部规则测试和边界情况测试通过；
- 随机策略 200 次全部在 60 天内完成目标；
- 报告里"白过的一天"比例为 0（目标导向策略）；
- 自己从标题玩到第一卷结尾一遍，记录实际时长。

## D2 · 叙事与表现

目标：故事在牌桌上讲，画面和声音达到 demo 质量。

- StoryPlayer 和全部插画页（含笔记版式、回忆换色）；唤醒演出；BanterDirector 和全部台词（含拖动嘀咕）；夜里小场景动画；牌桌彩蛋；长卷（冬春溶解、小人走动、全屏查看、结尾平移）。
- 全部正式像素美术（替换灰盒）。
- 全部音乐（含白天三层分轨）、短乐句、音效、环境声、说话音。
- 设置菜单。

**验收**：
- `npm run shots` 整套截图自己逐张看过，美术自查清单通过；
- `audio:check` 通过，每首曲子在游戏里听过并写下听感；分层音乐声部切换平滑；
- 从标题玩到结尾，没有占位图、没有静音操作、没有文字溢出。

## D3 · 试玩版

- 根据自动试玩和自己试玩调整：资源节奏、事件倒计时、发牌日程。
- 导出 macOS 版（Web 可选）；写一页试玩说明；整理问卷。
- 已知问题写进 backlog。

**验收**：导出包在干净机器上能打开并玩到结尾；试玩说明和问卷就绪；打标签 `demo-1`。

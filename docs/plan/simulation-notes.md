# D1 自动试玩：策略、证据与验收

状态：原始均匀随机 200 种子验收失败，永久保留；用户授权自行决策后采用明确版本化的验收 v2，最终 v2 重跑通过（退出 0）。不能把旧失败改称旧标准通过，也不能单凭模拟宣布整个 D1 人工验收完成。

## 运行

```sh
GODOT_BIN=/path/to/Godot-4.7.2 npm run sim
# 快速排错（直接调用 Godot，不能当完整验收）：
Godot-4.7.2 --headless --path godot --script res://tests/sim.gd -- --quick
```

常规入口写 `.local/sim/full/summary.json` 和每个策略/种子的独立 JSON。快速模式写 `.local/sim/quick/`，标记 `quick_smoke_not_acceptance`；不会覆盖完整结果。每个文件远小于 2 MB。失败保留最终状态、逐日命令、事件、哈希、资源最小余额、目标、新鲜事和白过判定。报告不写运行时钟，规范化 JSON 键排序，支持逐字节比较。v2 硬阈值失败以非零状态退出；报告中的原始阈值结果、安全性、是否完成与体验指标分别呈现。

## 三种真正不同的策略

- **目标导向**：每次从全部合法预览选最高分。优先有限进度、唤醒、探索、尚未触发的 ✦、匮乏资源；已经达到上限的 progress 不再得分。不是预设完成日期，不通过等待刻意拖到 12 天。seed `% 3` 形成三种明确偏好：中性、河岸 +45、药圃 +45。若实际行为没有差异，报告如实显示，不注入规则随机或伪造暴雨成功率。
- **纯随机**：种子 1–200；Park–Miller 整数 PRNG，先 Fisher–Yates 洗牌人物顺序，每人从当前合法 `(地点, 用法)` 与一个“休息”项等概率取样（整数模取样存在小于 1/2³¹ 的离散余数偏差）。每人最多一次，不根据目标、新鲜事、剩余天数或失败苗头加权。不会在后期换成目标策略。未使用冬眠诀是公开分布限制，不是“全部合法指令空间”的穷尽。
- **偷懒**：每天最多派一人，固定人物名册轮转，跳过未醒/无合法用法者。已醒人物都有公平机会；选择该人物的最高分合法动作。不尝试一天内无法发生的双人组合；明确降低非主链旧桥解冻优先级。不会永远只派阿暖。

三策略都执行同一免费教学 API，不直接改资源/目标/解锁。规则与内容保持只读，机器人自己的 RNG 不写入游戏 RNG。

## 安全性与活性分开

- v2 在每个实际教学/分派指令后和每次入夜后检查非负资源/escrow、人物行动数、地点容量、事件槽上限、分派 id 唯一、同人同地不可重复、不能派冻结人物、进度范围；每日另查目标与新鲜事不倒退。检查 hook 只读，不改规则或随机决策。
- 资源最低值包括分派预扣后的每次余额，不能仅看夜末净收入。
- **独立恢复实验**：种子 1–20 的随机行为先跑 20 天，明确从第 21 天切换目标策略，最多第 80 天。单独输出 `recovery-*`，绝不混入 200 次纯随机通过率。这是可达状态的反例搜索，不是所有状态都能完成的数学证明。
- 三种策略的 seed 1 独立重跑，比较完整规范化命令/事件/每日哈希报告；额外实验也独立重跑 seed 1。
- 无限休息合法，因此“所有任意策略一定在 60 天完成”不能从任何有限样本推出。

## 新东西统计

按原 playtest 定义：翻牌、新鲜事、新事件、唤醒、回春、目标步骤、首次笔记算新东西；普通收资源、普通故事/重复往事不算。早期报告未计入首日教学唤醒，后续版本已将教学 API 的事件并入当日新东西；原始文件保留，不覆盖。2026-10-26 集成者明确：水轮/筑坝的实际正向进度也是“目标推进”，即使未完成步骤；已经封顶的零增量不算。原始严格口径结果保留在 `.local/sim/first-full/`，澄清后重跑单独记录。新事件属于其真实清晨那一天，不能把次日发牌挪给前一晚。访客、往事保底各自计数；往事不抵消白过。统计到首次结尾，未完成样本统计满 60 天。

## 当前结果

原始严格口径（尚未把水轮/筑坝未完成的增量计为新东西）：

| 策略/指标 | 实测 | 结论 |
|---|---:|---|
| 目标 12 个种子完成天数 | 全部 12 天 | 通过 10–14 天 |
| 目标白过 | 0% | 通过 |
| 偷懒 12 个种子 | 全部 31 天 | 通过 ≤40 天 |
| 均匀随机 1–200，60 天 | 115/200，57.5% | **失败**，85 个未完成 |
| 随机白过 | 54.0309% | **失败** ≤10% |
| 随机平均新鲜事 | 84.7059% | 通过 ≥60% |
| 资源最小余额 / 不变量错误 | 三项最低均 0 / 0 | 本样本安全性通过 |
| 目标策略族暴雨完成 | 12/12，100% | **失败** 30–60%；偏好尚未形成不同路线 |
| 随机前 20 天后显式目标恢复 | 20/20，结束在 14–26 天 | 单独恢复样本通过；1 个提前结束 |

这不是 85 个永久死局：未完成样本全部已融开水磨；41 个仍未修好轮、15 个仍未完成引水、全部未唤醒磨坊一家，只有 6 个海狸未醒。大量样本资源富余（如 seed 23 已完成轮和水，有 112 石/95 暖意/46 木），主要原因是均匀随机在许多重复动作中稀释了关键人物的目标动作。随后对全部 85 个失败末态做明确目标恢复：**85/85 在额外 1–5 天内完成，零安全性错误**（`.local/sim/strict-full/failure-recovery-*.json`）。不能据此抹掉原始随机失败。

## 补充实验（不替代原始门槛）

- `-- --exploratory`：200 个相同种子，60 天。从第 1 天开始不变的探索偏好分布：所有合法动作基础权重 1，当前可用的 ✦ +8，探路/焐 +8，公开主链用法 `repair_wheel/warm_family/build_dam` +20，休息权重 1。每个人仍然只随机取一个选项，绝不在期限前切到目标 bot。保存为 `.local/sim/exploratory/`。
- `-- --long-random`：相同均匀分布、相同 200 种子，只将观察窗延到 180 天。保存为 `.local/sim/long-random/`。
- 补充实验报告标记 `experiment_not_original_acceptance` / `original_acceptance_passed:false`；其退出状态只表示安全性/复现是否正常，**绝不表示原始统计验收通过**。
- 所有报告保存内容 SHA-256，更新版另保存机器人、规则、模拟器源码 SHA-256。完整报告在忽略目录保留，仓库只保留摘要/少量代表性轨迹，避免提交数十 MB 重复记录。


## 2026-10-26：用户授权下的验收 v2

用户对验收冲突的原话是：**“你先自行决策，并做好说明就可以了”**。据此，集成者选择把“没有失败状态、任意可达状态有完成路径”与“均匀随机在固定期限恰好选中整条链”分开，而不是为了数字删除休息、偷偷接管随机机器人，或给游戏加自动通关。

这是**公开修改验收**，不是把旧报告改成绿色。`.local/sim/original-clarified-full/summary.json` 原样保留原始 `passed:false`；新的 `valley-simulation/2` 同时写 `original_acceptance_passed`、`revised_acceptance_passed`、两组失败原因。`npm run sim` 从此以 v2 硬门槛退出，但仍打印原始失败。

| v2 硬门槛 | 范围 |
|---|---|
| 安全性 | 200 个原始均匀随机轨迹的每条已执行指令/入夜均无不变量错误，保留休息 |
| 已采样末态有完成路径 | 原始 200 个样本：已经完成者 + 所有 60 天未完成末态显式目标恢复；后者应额外 ≤5 天全部完成 |
| 中途样本恢复 | 单独 20 种子随机 20 天后切目标，全部完成；不计入原始随机完成率 |
| 正常目标路线 | 10–14 天且白过 0% |
| 公平一人偷懒路线 | ≤40 天 |
| 可复现 | 独立 seed 1 全部命令/事件/每日哈希相同，内容/实现 SHA-256 写入报告 |

原始均匀随机 60 天完成率、白过率、组合率，以及单一目标路线族的暴雨率保留为信息指标。当前目标偏好族实际都走同一条救坝路线，因此 100% 暴雨完成不应解释为真实玩家人群比例；没有为了 30–60% 人为故意失败。**v2 仍只是固定样本反例搜索，不是所有无限可达状态的数学证明，也不替代用户实际试玩。**

### 已完成补充证据

探索偏好随机（明确不同分布，不是原始均匀随机）：200/200 在 10–30 天完成，白过 5.65058%，平均组合 89.7353%，暴雨完成 25%，不变量错误 0，资源最低三项均 0。`.local/sim/exploratory/summary.json` 保留完整分布、源码哈希和逐种子结果。它支持“可见提示引导探索的正常行为能完成”，不支持“所有任意随机行为都在 60 天完成”。180 天观察窗也已完成：同一均匀分布的 200/200 样本最终在 **14–143 天**完成，白过 56.9383%，平均组合 87.2647%，安全性错误 0（`.local/sim/long-random/summary.json`）。这独立支持“60 天失败主要是随机动作稀释”，没有修改任何规则或在后期换策略。v2 最终强化逐指令检查已通过，详见下节。


## 最终验证：v2 通过，原始阈值仍失败

2026-10-26，Godot 4.7.2 完整运行退出 **0**，不是 quick 模式。`.local/sim/full/summary.json` 明确记录：

- `original_acceptance_passed:false`：原始均匀随机仍只有 115/200 在 60 天内完成，澄清“正向目标进度”和首日教学事件后白过为 **52.1375%**；暴雨目标路线族仍 100%。不篡改早期 54.0309% 的报告，口径修正有单独记录。
- `revised_acceptance_passed:true`，`revised_failures:[]`：200 个原始随机样本每条执行指令/入夜均无不变量错误；115 个已完成 +85 个未完成末态全部在额外 1–5 天明确目标恢复，合计 **200/200 已采样末态存在已验证完成路径**。
- 目标路线 12/12 均为 12 天、白过 0%；公平每天一人路线 12/12 均为 31 天；另外 20 个中途恢复样本全部完成。
- 目标/偷懒/原始随机各 seed 1 的完整规范化报告独立重跑一致。最终报告中的五个实现源码 SHA-256 已与当前文件逐一复核一致。
- 探索偏好 200/200（10–30 天）和延长均匀窗口 200/200（14–143 天）仅为已标明的补充实验，不混入原始随机通过率。

完整逐日证据继续保留在忽略目录 `.local/sim/`。建议提交四份小摘要（`full`、`original-clarified-full`、`exploratory`、`long-random`）及必要的代表性失败/恢复轨迹即可；四摘要每份均不足 20 KB，不提交数十 MB 重复轨迹。实际从标题到结尾的手动试玩由集成者另行记录。

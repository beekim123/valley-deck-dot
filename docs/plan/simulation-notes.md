## 运行

```sh
GODOT_BIN=/path/to/Godot-4.7.2 npm run sim
# 快速排错（直接调用 Godot，不能当完整验收）：

```

常规入口写 `.local/sim/full/summary.json` 和每个策略/种子的独立 JSON。快速模式写 `.local/sim/quick/`，标记 `quick_smoke_not_acceptance`；不会覆盖完整结果。每个文件远小于 2 MB。失败保留最终状态、逐日命令、事件、哈希、资源最小余额、目标、新鲜事和白过判定。报告不写运行时钟，规范化 JSON 键排序，支持逐字节比较。阈值失败以非零状态退出；报告中的安全性、是否完成与体验指标分别呈现。

## 三种真正不同的策略

- **目标导向**：每次从全部合法预览选最高分。优先有限进度、唤醒、探索、尚未触发的 ✦、匮乏资源；已经达到上限的 progress 不再得分。不是预设完成日期，不通过等待刻意拖到 12 天。seed `% 3` 形成三种明确偏好：中性、河岸 +45、药圃 +45。若实际行为没有差异，报告如实显示，不注入规则随机或伪造暴雨成功率。
- **纯随机**：种子 1–200；Park–Miller 整数 PRNG，先 Fisher–Yates 洗牌人物顺序，每人从当前合法 `(地点, 用法)` 与一个“休息”项等概率取样（整数模取样存在小于 1/2³¹ 的离散余数偏差）。每人最多一次，不根据目标、新鲜事、剩余天数或失败苗头加权。不会在后期换成目标策略。未使用冬眠诀是公开分布限制，不是“全部合法指令空间”的穷尽。
- **偷懒**：每天最多派一人，固定人物名册轮转，跳过未醒/无合法用法者。已醒人物都有公平机会；选择该人物的最高分合法动作。不尝试一天内无法发生的双人组合；明确降低非主链旧桥解冻优先级。不会永远只派阿暖。

三策略都执行同一免费教学 API，不直接改资源/目标/解锁。规则与内容保持只读，机器人自己的 RNG 不写入游戏 RNG。

## 安全性与活性分开

- 所有样本检查非负资源/escrow、人物行动数、地点容量、事件槽上限、分派 id 唯一、目标与新鲜事不倒退。
- 资源最低值包括分派预扣后的每次余额，不能仅看夜末净收入。
- **独立恢复实验**：种子 1–20 的随机行为先跑 20 天，明确从第 21 天切换目标策略，最多第 80 天。单独输出 `recovery-*`，绝不混入 200 次纯随机通过率。这是可达状态的反例搜索，不是所有状态都能完成的数学证明。
- 三种策略的 seed 1 独立重跑，比较完整规范化命令/事件/每日哈希报告；额外实验也独立重跑 seed 1。
- 无限休息合法，因此“所有任意策略一定在 60 天完成”不能从任何有限样本推出。

## 新东西统计

按原 playtest 定义：翻牌、新鲜事、新事件、唤醒、回春、目标步骤、首次笔记算新东西；普通收资源、普通故事/重复往事不算。早期报告未计入首日教学唤醒，后续版本已将教学 API 的事件并入当日新东西；原始文件保留，不覆盖。2026-10-26 集成者明确：水轮/筑坝的实际正向进度也是“目标推进”，即使未完成步骤；已经封顶的零增量不算。原始严格口径结果保留在 `.local/sim/first-full/`，澄清后重跑单独记录。新事件属于其真实清晨那一天，不能把次日发牌挪给前一晚。访客、往事保底各自计数；往事不抵消白过。统计到首次结尾，未完成样本统计满 60 天。

## 当前结果

原始严格口径（尚未把水轮/筑坝未完成的增量计为新东西）：

| 策略/指标 | 实测 | 结论 |
|---|---:|---|
| 目标 12 个种子完成天数 | 全部 12 天 | 通过 10–14 天 |
| 目标白过 | 0% | 通过 |
| 偷懒 12 个种子 | 全部 31 天 | 通过 ≤40 天 |
| 均匀随机 1–200，60 天 | 115/200，57.5% | **失败**，85 个未完成 |
| 随机白过 | 54.0309% | **失败** ≤10% |
| 随机平均新鲜事 | 84.7059% | 通过 ≥60% |
| 资源最小余额 / 不变量错误 | 三项最低均 0 / 0 | 本样本安全性通过 |
| 目标策略族暴雨完成 | 12/12，100% | **失败** 30–60%；偏好尚未形成不同路线 |

这不是 85 个永久死局：未完成样本全部已融开水磨；41 个仍未修好轮、15 个仍未完成引水、全部未唤醒磨坊一家，只有 6 个海狸未醒。大量样本资源富余（如 seed 23 已完成轮和水，有 112 石/95 暖意/46 木），主要原因是均匀随机在许多重复动作中稀释了关键人物的目标动作。随后对全部 85 个失败末态做明确目标恢复：**85/85 在额外 1–5 天内完成，零安全性错误**（`.local/sim/strict-full/failure-recovery-*.json`）。不能据此抹掉原始随机失败。

## 补充实验（不替代原始门槛）

- `-- --exploratory`：200 个相同种子，60 天。从第 1 天开始不变的探索偏好分布：所有合法动作基础权重 1，当前可用的 ✦ +8，探路/焐 +8，公开主链用法 `repair_wheel/warm_family/build_dam` +20，休息权重 1。每个人仍然只随机取一个选项，绝不在期限前切到目标 bot。保存为 `.local/sim/exploratory/`。
- `-- --long-random`：相同均匀分布、相同 200 种子，只将观察窗延到 180 天。保存为 `.local/sim/long-random/`。
- 补充实验报告标记 `experiment_not_original_acceptance` / `original_acceptance_passed:false`；其退出状态只表示安全性/复现是否正常，**绝不表示原始统计验收通过**。
- 所有报告保存内容 SHA-256，更新版另保存机器人、规则、模拟器源码 SHA-256。完整报告在忽略目录保留，仓库只保留摘要/少量代表性轨迹，避免提交数十 MB 重复记录。

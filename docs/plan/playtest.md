# 试玩验证计划

> 2026-10-26 验证修订：D1 的最终门槛以 [验收口径 v2](acceptance-v2.md) 为准。下文原始指标保留作基线，不改写已失败的结果。
Demo 的目的就是回答下面这些问题。每个问题都有：怎么测、合格线、不合格时先改什么。合格线是初稿，用户可以改。

## 1 自动试玩的目标区间（D1 起每次改内容都要跑）

| 指标 | 目标 |
|---|---|
| 随机策略：200 次中在 60 天内完成目标的比例 | 100%（不允许卡死） |
| 偷懒策略（每天只派一人）：完成天数 | ≤ 40 天 |
| 目标导向策略：完成天数 | 10–14 天 |
| 目标导向策略："白过的一天"比例 | 0% |
| 随机策略："白过的一天"比例 | ≤ 10% |
| 17 条新鲜事在随机策略下的平均触发比例 | ≥ 60%（太低说明藏得太深） |
| 暴雨事件在目标导向策略下的完成率 | 30–60%（让一部分玩家看到"涨水后的河滩"） |

"白过的一天"：当天的结算里没有任何一项"新东西"（翻牌、新鲜事、新事件、唤醒、回春、目标推进、笔记）。

## 2 用户试玩要回答的问题

### Q1 拖放加预览，能不能让人轻松地玩、不去算最优解？

- 观察：每天分派花多长时间；有没有反复拖来拖去、算资源；问"有没有觉得在做数学题"。
- 合格：大多数天在 1 分钟内分派完；没有"在算账"的感受。
- 不合格先改：减少需要预扣的用法；资源更宽裕；让目标卡的提示更直接。

### Q2 每天都有新鲜感吗？

- 观察：每天结束时问"今天有没有什么让你想看下去的"；记录用户说"没意思"的天数。
- 合格：没有一天被评价为"白过"；用户能举出至少 3 条印象深刻的新鲜事。
- 不合格先改：加新鲜事；保底访客更有趣；事件日程更密。

### Q3 没有战斗，还觉得好玩吗？

- 观察：问"有没有想过'要是能打架就好了'"；整体好玩评分。
- 合格：整体好玩 ≥ 3.5/5，不把"没有战斗"列为主要缺点。
- 不合格先改：先加强发现与唤醒，而不是加战斗（"刻意不做"清单里有战斗）。

### Q4 长卷和唤醒有没有足够的成就感？

- 观察：有没有主动点开长卷看；唤醒演出有没有跳过；结尾长卷平移时的反应。
- 合格：至少主动看过一次长卷；唤醒演出跳过率低于 30%。
- 不合格先改：长卷更显眼（回春时自动滚到那一段）；唤醒台词更好。

### Q5 事件过期的"温和结局"有没有被理解成失败？

- 观察：事件过期时用户的反应；问"桥被淹的时候是什么感觉"。
- 合格：没有人觉得被惩罚；有人觉得"这样也不错"。
- 不合格先改：过期结果给更明显的补偿（新牌、新故事）。

## 3 试玩后问卷（给用户）

1. 一共玩了多久？用了几天完成第一卷？
2. 印象最深的一条新鲜事是什么？
3. 唤醒哪个人的时候最有感觉？
4. 有没有哪一天觉得没意思？是第几天、为什么？
5. 有没有觉得在"算账"？在哪里？
6. 有没有主动去看长卷？
7. 暴雨的事件你挡住了吗？没挡住的话，感觉怎么样？
8. 最想吐槽的一个地方？
9. 最想保留的一个地方？
10. 如果有第二卷，想不想继续玩？（1–5 分）
11. 整体好玩程度（1–5 分）

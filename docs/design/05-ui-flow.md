# 05 · 界面流程

## 1 画面规格【建议】

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | **640×360**，整数倍放大，最近邻采样，多余部分黑边 |
| 字体 | Fusion Pixel 12px；大标题 24px |
| 面板 | 九宫格边框，不透明底色，不用渐变 |
| 操作 | 鼠标拖拽为主；右键取消；键盘快捷键为辅 |

## 2 画面流程

```text
启动 → 标题 → 卷轴匣（继续 / 新游戏 / 第一卷）
  → 开场插画 → 牌桌（一天一天循环）
       ├ 点长卷 → 长卷全屏
       ├ 插画页（笔记、唤醒回忆、事件、结尾）
       └ Esc → 暂停菜单：继续 / 设置 / 回到卷轴匣
  → 结尾插画 → 卷轴匣（第二卷预告）
```

| 元素 | 尺寸【建议】 | 说明 |
|---|---|---|
| 长卷视窗 | 640×80 | 顶部，滚轮/拖动左右滚 |
| 地点牌 | **72×96** | 牌面小场景 64×48、名字、状态图标、进度条、已分派人物的小头像（最多 3 个，贴在牌下沿） |
| 人物牌 | **48×64** | 头像 40×40 + 名字 + 特长图标；今天已分派的牌变暗并显示去了哪 |
| 事件牌 | 112×72 | 名字、要做什么、倒计时圆盘、完成/过期两行小字 |
| 目标卡 | 96×64 | 左上角，四个步骤的勾选框 |
| 资源 | 计数筹码 | 显示"现有 → 分派后剩余" |

## 4 交互细节

### 4.1 拖动人物牌

1. 按住人物牌 → 牌稍微放大跟随鼠标。
2. 有用法的地点牌亮起描边，没用法的变暗。
3. 停在某张地点上方 → 0.2 秒后弹出**预览框**（地点牌旁边）：

```text
┌──────────────────┐
│ 托比 → 松林        │
│ 伐木：+2 木        │
│ ✦ 好像会有新鲜事    │
└──────────────────┘
```

4. 0.4 秒后，这个人冒一句"拖动嘀咕"。
5. 松手 → 分派成功（音效 + 牌贴到地点下沿）。有多种用法时弹出小选择框。
6. 把已分派的人从地点下沿拖回手里或拖到别处，即可撤销。

### 4.2 悬停

- 悬停地点牌：显示大卡（144×192），列出这张地点所有用法、谁能做、回春条件、每日产出。
- 悬停事件牌：相关地点描边高亮。
- 悬停目标卡的某一步：相关地点高亮 + 一句提示。

### 4.3 入夜

- 点「入夜」后桌面压暗，每张有人的地点牌依次放大到中央播放小场景，资源飞到桌角。
- 按住鼠标左键 2 倍速；设置里可选"简短"。
- 结算完毕弹出一日小结面板（获得了什么、发生了什么），点击进入下一天清晨。

## 5 操作一览

| 操作 | 鼠标 | 键盘 |
|---|---|---|
| 分派 | 拖人物牌到地点牌 | 1–9 选人物，方向键选地点，回车确认 |
| 撤销分派 | 拖回手里 / 右键点已分派的人 | Backspace |
| 入夜 | 点按钮 | N |
| 看长卷 | 点长卷 / 滚轮 | V |
| 翻页、跳过台词 | 点击 | 空格 / 回车 |
| 暂停 | — | Esc |

## 6 反馈与可读性【定】

- 每次拖、放、撤销都有声音和动画反馈；不能放时有轻微的"不行"音效和抖动。
- 地点牌的四种状态外观差异要大：雾（牌背）、霜封（厚冰 + 花费数字）、解冻（冬天牌面）、回春（春天牌面 + 小花边）。
- 进度型用法在牌面上显示进度条（例如"修水轮 1/2"）。
- 所有预览数字都从规则层的 preview 接口读，界面不自己算。
- 设置：主音量、音乐、音效、文字速度、夜间结算速度（正常/简短）、窗口倍数、全屏。

## 7 调试功能（只在调试版）

- F1 调试面板：跳到第 N 天；资源 +10；唤醒/翻开/回春指定的牌；触发指定新鲜事；显示所有新鲜事的完成情况。
- F2 所有台词立即显示（检查文字溢出）。

# 02 · 规则细则

所有数值都是初稿，**待原型验证**。数值写在 `content/data/`，代码里不写死。

## 1 全局流程

```text
标题 → 卷轴匣（章节选择 / 继续）→ 开场插画 → 牌桌
  每天：清晨 → 白天（分派）→ 入夜（结算）→ 一日小结 → 下一天
  章节目标完成 → 结尾插画 → 卷轴匣（第二卷预告）
```

没有失败状态，没有天数上限。

## 2 牌桌上的东西

| 东西 | 位置 | 说明 |
|---|---|---|
| 山谷长卷 | 顶部横条 | 侧视风景，地点回春后这一段变成春天；纯展示，可以点开全屏看 |
| 地点牌 | 中间，两排槽位 | 有四种状态（见第 3 节） |
| 人物牌 | 底部"手里" | 醒着的人，每天可以行动 1 次 |
| 事件牌 | 右侧一列 | 带倒计时的小任务，最多同时 3 张 |
| 冬眠诀 | 底部手里，人物牌旁边 | 一次性牌 |
| 资源 | 桌角计数筹码 | 木、石、暖意 |
| 章节目标卡 | 左上角 | 四个步骤，完成一个划掉一个 |
| 小烬 | 桌角铁灯笼 | 旁白 |

## 3 地点牌的状态

```text
雾（背面）──探路──→ 解冻 / 霜封
霜封 ──阿暖焐（花暖意）──→ 解冻
解冻 ──满足回春条件──→ 回春
```

| 状态 | 外观 | 能做什么 |
|---|---|---|
| 雾 | 牌背：霜花纹 + 柏翁的松枝火苗印记 | 任何人都可以来「探路」，当晚翻开；一张雾牌一天只能来一个人 |
| 霜封 | 牌面被厚冰盖住，只能隐约看到画面 | 只有阿暖能「焐」，花费写在冰上（例如"暖意 3"） |
| 解冻 | 冬天的牌面（雪、枯枝） | 有 2–4 种用法 |
| 回春 | 春天的牌面；长卷上对应的一段变成春天 | 用法不变，通常多一个每天自动产出 |

有些人物牌一开始是**冻住的**：冻在某张霜封的地点牌里（冰层下能看到一个人影）。阿暖在那张地点上**焐一次，就同时融开地点、唤醒里面的人**，花费写在冰上（例如药圃"暖意 3"）。

例外：
- 老水磨要焐两次：第一次融开水磨（目标第 1 步），磨坊一家要等水轮修好、河水引来后再焐一次（目标第 4 步）。
- 教学里的托比和米拉是两张冻住的人物牌，直接点击就能唤醒（小烬分火，不花暖意），只在第 1 天出现。

## 4 一天

### 4.1 清晨

1. 天数 +1，自动存档。
2. 回春地点的每日产出到账（例如花坡回春后，每天清晨 +1 暖意）。
3. 发事件牌（按内容表的日程和触发条件）。
4. **保底检查**【定】：如果今天桌面上既没有可翻的雾牌、也没有可触发的 ✦ 新鲜事、也没有新事件，就发一张"访客"小事件。保证不会有"白过的一天"。
5. 小烬说一句当天的开场白。

### 4.2 白天：分派

- 把一张人物牌拖到一张地点牌上。拖动时：
  - 这个人在这里**有用法**的地点亮起来，没用法的变暗；
  - 停在某张地点上方时，弹出**预览**：用法名 + 结果，例如"伐木：+2 木"、"探路：翻开这张牌"、"焐：暖意 -3，唤醒老梅"；
  - 有没触发过的新鲜事时，预览里显示 **✦ 好像会有新鲜事**（不说是什么）；
  - 资源不够时，预览显示灰色"暖意不够（2/3）"，不能放下。
- 松手即分派。人物牌立在地点牌下沿，占一个小位置。
- 同一个人在同一张地点有多种用法时，松手后弹出一个小选择框（2–3 个按钮，默认选中最特别的那个：新鲜事 > 特长 > 通用）。
- **资源在分派时就预扣**。资源条上显示"现有 / 分派后剩余"。
- 入夜前，可以把任何人拖回手里或拖到别处，**不花任何代价**。
- 一张地点牌一天最多容纳 3 个人。
- 冬眠诀：拖到桌面上松手就生效，当天有效，用掉就没了。
- 不必把所有人都派出去。没派的人当天休息（不产出、不扣东西）。

### 4.3 入夜：结算

点「入夜」后：

1. 按地点牌在桌上的顺序（第一排从左到右，再第二排）逐张结算。
2. 每张有人的地点牌：牌面放大到中央，播放 2–3 秒的小场景动画（人物在牌面里干活），配一句台词；资源图标从牌面飞到桌角；状态变化（翻开、融冰、唤醒、回春）当场播放。
3. 同一张地点上的多个人，按放上去的顺序结算；有双人新鲜事时，先播双人新鲜事。
4. 全部结算完后，事件牌倒计时 -1；倒计时到 0 的事件按"过期"结算。
5. 回春判定：满足条件的地点播放回春动画，长卷对应的一段由冬变春。
6. 一日小结：本日获得的资源、翻开/唤醒/回春的东西、小烬的一句话。

- 结算动画可以按住鼠标加速（2 倍），也可以在设置里设为"简短"（每张 1 秒）。

### 4.4 用法的结算规则

- 每个用法是一串操作（获得资源、翻开、焐、推进进度、触发剧情……），全部在结算时执行。
- 预扣的资源在结算时正式扣除；结算顺序不会改变结果（因为已经预扣）。
- **进度型用法**（例如"修水轮 0/2"）：每次结算 +1，到满为止。进度条画在地点牌上。
- **新鲜事**：每条只触发一次（双人新鲜事要求两个人当天都在这张地点上）。触发后，这对"人物 × 地点"的预览不再显示 ✦。

## 5 资源

| 资源 | 开局 | 来源（例） | 去处（例） |
|---|---|---|---|
| 木 | 2 | 松林伐木 +2、拾柴 +1、河湾捡浮木 +1、海狸啃木 +2 | 生火、修水轮、加固旧桥 |
| 石 | 0 | 碎石滩搬石 +2、捡石头 +1、河湾凿冰 +1 | 修水轮 |
| 暖意 | 3 | 柏翁小屋生火（1 木 → 1 暖意）、花坡晒太阳 +1、老梅采药 +1 | 阿暖焐地点和人 |

- 没有上限。
- 【定】**每种资源至少有一个"不需要条件、不花东西"的来源**（木：松林拾柴；石：碎石滩捡石头；暖意：花坡晒太阳），所以无论怎么分派都不会卡死。碎石滩和花坡开局是雾牌，但探路本身任何人、任何一天都能免费做，所以这些来源永远拿得到。自动试玩要验证这一点（见 architecture）。

## 6 事件牌

- 每张事件牌写明：**要做什么**、**倒计时几天**、**完成了会怎样**、**过期了会怎样**。四项都直接写在牌上，不藏。
- 鼠标悬停事件牌，相关的地点牌描边高亮。
- 完成判定在入夜结算时进行；完成后事件牌播放完成动画并移除。
- 过期结果【定】：只会走向另一个温和的结果，不会毁掉任何东西，也不会让目标无法完成。例如"旧桥一带三天不能用，水退后出现新牌『涨水后的河滩』"。
- 同时最多 3 张事件牌，第 4 张会等到有空位再发。

## 7 冬眠诀

- 柏翁留下的一次性牌，通过新鲜事或事件获得。
- 当天改写一条规则，例如"今天一个人可以行动两次"。
- 白天拖到桌面上使用；用掉后从手里消失。不使用可以一直留着。

## 8 章节目标

- 第一卷目标"让老水磨重新转起来"，分四个步骤（见 [01-world-story.md](01-world-story.md)）。
- 目标卡上的每个步骤，悬停时高亮相关的地点牌，并用一句话提示下一步该找什么（"水轮修好了，但是没有水……河湾那边有什么能挡水的？"）。
- 四步全部完成的当晚，进入结尾插画。之后可以选择"继续在山谷里待着"（自由玩，没有新目标）或"回到卷轴匣"。

## 9 永久成长（Demo 范围内）

- 人越来越多：每唤醒一个人，手里多一张牌、每天多一次行动。
- 特长升级：一些事件和新鲜事会让某个人的用法变强（例如托比的斧头磨好以后，伐木 +3）。
- 回春的地方有每日产出：山谷越活，资源越宽裕，后面的天数越轻松。

## 10 存档

- 每天清晨自动存档；白天的分派不存（退出再进时回到当天清晨，分派清空）。
- 读取失败：坏文件改名备份，回到标题，不崩溃。

## 11 边界情况清单

| 情况 | 处理 |
|---|---|
| 两个人想同一天探同一张雾牌 | 第二个人拖上去时该雾牌显示"已有人去了"，不能放 |
| 资源不够 | 预览灰色，不能放下 |
| 分派后又把人挪走 | 预扣的资源退回 |
| 事件要求的地点被另一个事件弄得暂时不能用（例如被淹） | 被淹期间该事件的倒计时暂停 |
| 冻住的人所在的地点还是雾牌 | 先探路，翻开后才看得见冰壳里的人 |
| 同一天同一张地点上既有单人新鲜事又有双人新鲜事 | 先双人，再单人 |
| 目标步骤的前置还没完成就做了后面的（例如先引来河水再修水轮） | 允许，顺序不限，四步都完成就行 |
| 玩家连续几天什么都不派 | 允许；第三天起小烬会提醒一次 |
| 冬眠诀"一人两用" | 被选中的那个人当天可以分派到两张不同的地点牌上 |

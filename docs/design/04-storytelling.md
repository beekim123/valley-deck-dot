# 04 · 牌桌上的叙事（炉石冒险式）

【定】**不做俯视地图，也不做角色在地图上走动的探索。** 故事全部在"卷轴匣 + 插画页 + 牌桌 + 长卷"上讲。

参考《炉石传说》冒险模式的**表现手法**：旁白人物、插画分镜页、关键时刻的大演出、对局中的台词、可以点的牌桌。只学手法，不复刻它的界面图形、名字和文本。

## 1 叙事组件总览

| 组件 | 在哪出现 | 做什么 |
|---|---|---|
| 卷轴匣（冒险书） | 标题之后 | 柏翁的木匣子里放着几卷画轴，每一卷是一章。第一卷「河湾」可以打开，第二卷「磨坊坡」上锁，系着柏翁写的小纸条 |
| 插画页 | 开场、笔记、唤醒回忆、事件完成、结尾 | 一页一幅像素插画 + 1–2 行文字 |
| 唤醒演出 | 每次唤醒一个人 | 冰壳裂开、人跳出来、接着冻住前那一刻说第一句话 |
| 牌桌台词 | 全程 | 小烬、村民、访客冒出的气泡 |
| 拖动嘀咕 | 白天拖人物牌时 | 拖到某张地点上方时，这个人小声说一句对这个地方的看法 |
| 夜里小场景 | 入夜结算 | 每个用法在牌面里放一段小动画，配一句话 |
| 山谷长卷 | 顶部，常驻 | 回春的地方变成春天，醒来的人在上面走；可以点开全屏，点人会说话 |
| 牌桌彩蛋 | 全程 | 柏翁桌上的小物件，点了有反应 |

## 2 插画页

### 2.1 规格【建议】

- 书页边框里放一幅 **320×180** 的插画，下方旁白框（每页最多 2 行、50 字）。
- 插画由**图层拼成**：背景 + 人物大立绘 + 道具 + 前景，每层可以有 2–4 帧小循环（炉火、落雪、呼出的白气），也可以整数像素慢速平移。
- **柏翁笔记**用另一种版式：泛黄的纸页，左边是柏翁的速写（小插画 160×120），右边是手写体排版的文字（仍然用像素字体，颜色用墨色，行距放宽）。
- **回忆页**用换色表导出的冷蓝单色版本（"冻住前的那一刻"）。
- 点击、空格、回车翻页；右上角"跳过"。

数据格式与《拾遗井》相同：`content/story/pages.json`，每页 `layers` + `speaker` + `text`，可以带 `when` 条件。

## 3 唤醒演出【定·体验】

唤醒是本作最重要的"高光时刻"，每次都要完整播放（第二次起可以点击加速）：

1. 冻住的人物牌从地点牌上飞到桌面中央，放大。
2. 阿暖的手按上去，小烬的火苗顺着手臂流过去。
3. 冰壳出现三道裂纹（每道一声冰裂音），第三下碎开（冰碴特效）。
4. 牌面从冷蓝单色变回彩色（溶解动画），人物从牌框里探出半个身子，伸懒腰。
5. 第一句话：**接着冻住前那一刻的事**（台词见第 2 节和下表）。
6. （可跳过）回忆插画页 1–2 页。
7. 人物牌飞进手里，长卷上这个人的小人出现在他所在的那一段。

| 人物 | 醒来第一句 |
|---|---|
| 托比 | 「……嗯？雪停了？」 |
| 米拉 | 「兔子呢？！」 |
| 老梅 | 「我的姜茶呢？」 |
| 海狸一家 | 「最后一根呢？？？」 |
| 磨坊一家 | 谷叔：「水……水来了？」 |

## 4 牌桌台词

### 4.1 规则【建议】

- 说话人：**小烬**（桌角灯笼）、**村民**（人物牌上方或牌面小场景里）、**访客**（事件牌上方）。
- 气泡**不挡操作**，显示时长 = 2.5 秒 + 每字 0.08 秒；同一个说话人同时只有一个气泡；普通台词全局冷却 4 秒。
- **拖动嘀咕**：拖着人物停在一张地点上方 0.4 秒后，这个人冒一句对这里的看法。同一对"人物 × 地点"每天只说一次。
- 有逐字说话音（每个人一种音色），不做配音。

### 4.2 触发事件表

`content/story/banter.json`，记录格式同《拾遗井》：`{ id, event, speaker, when, lines[], once, chance, priority }`。

| event | 说明 |
|---|---|
| day_start | 清晨，带天数 |
| drag_hover | 拖动停在地点上，带人物、地点 |
| assign | 放下分派，带人物、地点、用法 |
| resolve | 夜里结算一个用法 |
| combo | 新鲜事触发 |
| flip / thaw / awaken / restore | 翻开 / 焐开 / 唤醒 / 回春 |
| event_new / event_done / event_expire | 事件出现 / 完成 / 过期 |
| goal_step | 目标完成一步 |
| spell_used | 用了冬眠诀 |
| idle | 30 秒没有操作 |
| night_empty | 一个人都没派就入夜 |
| deco_poke | 点了桌上的彩蛋 |

### 4.3 台词（示例，可扩写）

**小烬**（旁白、教学、吐槽）

| 触发 | 台词 |
|---|---|
| 教学·第一次拖人 | 「拖过去看看，会告诉你能干嘛。」 |
| 教学·第一次看到 ✦ | 「这个闪闪的，是有新鲜事！我也不知道是啥！」 |
| 教学·第一次入夜 | 「点'入夜'，大家就去干活啦。」 |
| day_start（随机） | 「早！今天也冷死了！」／「今天太阳不错，我感觉我能烧旺一点。」 |
| event_new（暴雨） | 「要下大雨？我最怕水了！」 |
| event_expire（暴雨） | 「淹了……没事没事，水总会退的。」 |
| restore（第一次） | 「看上面！那一块变绿了！」 |
| idle | 「……老头子以前摆牌也这么慢。」 |
| night_empty | 「今天大家都歇着？也行，十年都歇过来了。」 |

## 5 山谷长卷

- 顶部常驻的横条（640×80 的视窗），整幅长卷约 1400×80，可以用滚轮或拖动左右看。
- 每个地点对应长卷上固定的一段（顺序见 03 第 2 节"长卷位置"）。还没发现的地点在长卷上是一片空白雪地。
- 地点被发现：那一段淡入冬天的版本。回春：那一段从冬变春（溶解动画，约 2 秒），伴随一个短乐句。
- 醒着的人以 16×24 的小人出现在他今天所在地点对应的那一段，来回走动、干活（夜里回家）。
- 点长卷 → 全屏查看；点小人 → 这个人说一句（从"闲聊"台词池随机）。
- 第一卷结尾：长卷从左到右完整平移一遍。

## 6 牌桌彩蛋

| 装饰 | 点 1 次 | 连点反应 |
|---|---|---|
| 茶杯 | 冒一缕热气 | 第 5 次：小烬「别往我身上倒！」 |
| 烟斗 | 吐一个烟圈 | 第 3 次：烟圈套在小烬头上 |
| 窗户 | 雪下得大一点 | 回春的地点越多，窗外越春天：飘雪 → 化雪 → 有鸟 → 落花 |
| 小烬的灯笼 | 小烬跳一下「干嘛！」 | 第 10 次：小烬背过身去生气，一天不说话 |
| 墙上的旧挂钟 | 不动（停在长冬那一夜） | 第一卷结尾之后，**它开始走了**（不提示，留给玩家发现） |

## 7 揭示动画

| 演出 | 时长 | 过程 |
|---|---|---|
| 翻开雾牌 | 0.6 秒 | 牌翻面，霜花纹碎成小雪花飘走 |
| 焐开霜封 | 1.2 秒 | 冰面裂三下后碎开，牌面露出来 |
| 回春 | 2 秒 | 牌面冬→春溶解；长卷对应一段同步溶解；短乐句 |
| 新鲜事 | 1.5 秒 | ✦ 从牌面弹出，放大，夜里小场景换成专属动画 |
| 事件完成 | 1 秒 | 事件牌盖一个"好了"的章，飞走 |
| 事件过期 | 1 秒 | 事件牌轻轻翻过去，背面写着"换一种结局"，然后执行过期结果 |

# 01 · 世界、人物与 Demo 剧本

所有名字都是暂定，可以改，改了要同步改 `content/`。

## 1 世界【建议】

- **晴溪谷**：群山里的小山谷，一条溪流穿过，有松林、花坡、水磨、旧桥。几十户人家，谁家的猫跑到谁家吃饭都知道。
- **长冬**：十年前从北边白山压下来的一场冬天，一下就是十年。被长冬冻住太久的东西，会慢慢忘了自己是谁。
- **牌术与霜牌**：守谷人代代相传的手艺，能把一处地方、一个人"收"进一张牌里。牌里的时间是停住的，人不会老，也不会忘。
- **柏翁**：上一任守谷人。长冬压下来的那个晚上，他把整座山谷一张一张收进牌里，最后把这副牌和炉子里的火种交给学徒，送上最后一辆往南的车。他自己没有上车，他在最后一张牌里。（Demo 里找不到这张牌，只有笔记里的线索。）
- **春天**：今年白山的雪线退了。阿暖带着牌回来了。

## 2 人物

### 主角：阿暖【建议】

- 柏翁的学徒。十年前被送走时 8 岁，现在 18 岁。在南方的城里长大，回来时谷里只剩白茫茫一片和一张旧桌子。
- 性格：话不多、很认真，偶尔冒出一句冷笑话。心里有一个疙瘩：师父为什么不跟我一起走？
- 外观：短发，旧棉袄外面套一件师父的大坎肩（太大了），腰上挂一盏装着小烬的铁灯笼。配色是灰蓝棉袄 + 橘红围巾。
- 在牌桌上：阿暖是一张人物牌，特长「焐」。

### 旁白与向导：小烬【定·角色定位】

- 柏翁炉子里的一粒火种，住在阿暖腰上的小铁灯笼里，会说话。
- 性格：话痨、爱逞强、怕水、一着急火苗就窜高。管柏翁叫"老头子"。
- 职责：教学、每天的开场和收尾、提醒倒计时、吐槽、在关键剧情里替不在场的柏翁说一两句。
- 在牌桌画面里待在桌角的铁灯笼里，说话时火苗跳动。

### 柏翁【定·主线钩子】

## 3 Demo 剧本（逐场）

### S0 开场插画（4 页）

1. 雪山脚下，一辆旧车停在白茫茫的山谷口，阿暖背着包下车。*「十年了。」*
2. 谷里所有的房子、树、桥，都只剩雪的轮廓。阿暖推开柏翁的小屋，屋里只有一张桌子，桌上摆着一副牌。*「师父说：春天来了就回来，把牌摆开。」*
3. 阿暖打开铁灯笼，小烬"噗"地窜起来。小烬：*「冷死了冷死了！……咦？你长这么高了？」*
4. 阿暖把第一张牌放到桌上，牌面的霜慢慢化开。*「那就……开始吧。」*

### S1 第 1 天（教学）

- 小烬讲解桌面：上面是长卷（现在只有一片雪），中间是地点牌，下面是手里的人物牌，右边是事件，桌角是资源。
- 教学焐：桌上有两张冻住的人物牌「托比」「米拉」，小烬把自己的一点火分给阿暖（这一天的暖意免费）。阿暖焐醒托比 → 唤醒演出 → 再焐醒米拉。
- 教学分派：托比拖到松林（预览"伐木：+2 木"）；米拉拖到一张雾牌（预览"探路：翻开这张牌"）；阿暖拖到柏翁小屋（预览"读笔记 ✦"）。
- 点「入夜」→ 夜里逐张结算 → 小烬做一日小结。
- 第一页柏翁笔记（见 04）。

### S2 第 2–11 天（自由推进）

章节目标卡固定在桌面左上角：「第一卷：让老水磨重新转起来」，下面是四个小步骤，完成一个划掉一个：

1. 融开水磨的冰（阿暖焐，暖意 4）
2. 修好水轮（托比，木 3 石 2，两天）
3. 把河水引过来（海狸一家在河湾筑坝）
4. 唤醒磨坊一家（阿暖焐，暖意 3）

步骤 3 需要先找到海狸一家，海狸一家藏在雾中河岸，而雾中河岸要米拉在河湾打水漂才会出现。这条链就是第一卷的"发现主线"。

期间的事件、新鲜事、唤醒老梅、发现树洞，见 [03-content.md](03-content.md)。

### S3 第一卷结尾

触发：步骤 4 完成的那个夜里。

1. 水轮吱呀一声开始转，冰碴从水槽里冲出来（插画）。
2. 谷叔揉着眼睛从磨坊里出来，小粟抱着他的腿："爹，你胡子上有冰。"
3. 长卷整卷播放一遍：从松林到旧桥，每一段都是春天，醒来的人在上面走。音乐所有声部都响起来。
4. 小烬：*「老头子，你看见没？」* 阿暖在柏翁的桌上找到第四页笔记的一角，只有一句：*「对岸的灯，替我——」* 后面被水泡糊了。
5. 长卷卷起来，第二卷「磨坊坡」上锁的预告页：*「未完待续」*。

## 4 写作风格【建议】

- 台词短：桌上的气泡每句不超过 18 个字，插画页每页不超过 50 个字。
- 每个人一个说话习惯：小烬说话带"冷死了""烫烫烫"；托比说话慢、常以"嗯……"开头；米拉连问三个问题；老梅嘴上嫌弃，句尾总是一句关心；大板牙全靠吼，句尾三个感叹号。
- 冻住十年的人醒来，第一句话总是接着冻住前那一刻的事（老梅："我的姜茶呢？"），这是唤醒的笑点也是泪点。
- 柏翁的笔记不直接解释"为什么不走"，用生活细节一点点透露。

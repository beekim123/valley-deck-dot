# 声音制作源

全部由此目录的纯 TypeScript 合成器离线生成。没有录音、外部采样、生成模型或借用旋律。游戏只播放导出的 WAV；此目录不依赖 Godot 或游戏内容数据。

## 构建与验证

Node 22.13+，无 npm 依赖：

```sh
node --experimental-strip-types tools/resources/audio-pack.ts build
node --experimental-strip-types tools/resources/audio-pack.ts check
node --experimental-strip-types --test tests/audio.test.mjs
```

对应仓库命令 `npm run audio:build` / `npm run audio:check`。`check` 只读，不会用重新生成的文件覆盖错误产物。

- `cues/d0.ts` 是音符、音色和固定种子的唯一来源。
- `synth.ts` 的 `renderCue` 返回 PCM16；所有噪声由固定种子 PRNG 产生。
- `export/manifest.json` 为 `audio/1`，`assets` 中的 `file` 相对于此 `export/`；`hash` 为完整 WAV 的 SHA-256。清单没有时间戳或绝对路径。
- 数值验证包括双次逐字节比较、已保存产物比较、WAV 头、单声道 PCM16、采样率、长度、文件小于 2 MB、峰值 ≤ −1 dBFS、音乐 RMS −20 ±2 dBFS / 音效 −18 ±3 dBFS。
- 首尾样本必须为零，边界邻接样本幅度 ≤ 32 PCM 单位（约 −60 dBFS），避免只检验一个零点却留下突变；音符与整段都使用平滑边缘包络。分层曲目以后设置同一 `layerGroup`，检查器会核对采样率、帧数和循环模式。
- 不使用削波来强行满足响度；归一化后超峰值则报错，需要修改编配。

|---|---:|---:|---|

### D0《春醒谣》试奏版本

3/4 拍，90 BPM，四小节；每个数字代表八分音符数量，每小节 6 个，共 24 个 = 8 秒。

```text
| G4×2 B4×1 A4×1 D5×2 |
| E5×2 D5×3 B4×1      |
| G4×3 A4×1 C5×2      |
| B4×2 A4×4           |
```

从 G4 向上探到 E5，再退回低处，最后停在 A4、不落回主音。相比文档示例的改写是为这段 8 秒管线试奏单独创作；保留“从低处向上爬、最后悬着”的轮廓，不替代 D2 的最终曲谱。音色为双算子 FM，快速柔和起音、慢衰减；单旋律，无和声及伴奏。没有引用任何外部作品。

## D0 历史 QA 记录与当时剩余范围

2026-10-26：三段通过自动数值检查及负面测试（损坏 WAV、静音、超峰值、非零接缝、错误采样率、无效音符）。PCM16 量化后的 RMS 约 −20.0003 / −18.0003 dBFS；完整精确结果与 SHA-256 见清单。

**听感尚未验收**：数值合格不代表好听；需要在 Godot 实际播放，确认木质落牌、温和冰裂、音乐重复时的呼吸感和相对音量后记录，不把自动检查冒称为听过。D2 的正式音乐、分层声部、全部音效与环境声尚未制作。Godot 导入应保持 PCM、音乐前向循环，运行时由 AudioService 控制音量与首次点击启声。

# D2 正式声轨与运行时（2026-10-26）

`cues/d2.ts` 提供全部正式声音，D0 三个源与 WAV 字节保持不变。
原创最终动机（3/4，每格八分音符）：

```text
| G4×2 A4×1 B4×1 D5×2 |
| E5×3 D5×1 B4×2      |
| G4×2 E4×1 G4×1 C5×2 |
| B4×2 A4×4           |
```

从低处探到 E5，末尾 A4 悬而不落；只有 `music.ending` 的最后一轮最后一音改为 G4。
结尾最后一小节伴奏也回到 G 大三和弦，木笛最后落 G4。
这不是引用既有旋律。和声根音 G3 / E3 / C3 / D3，与不同速度和音色构成统一主题。

| 正式曲目 | BPM / 小节 | 时长 | 配器 |
|---|---|---:|---|
| title | 72 / 8 | 20 s | FM 八音盒 + 低声慢起三角铺底，留白、期待 |
| day.l1 | 88 / 8 | 16.363636 s | 同主题八音盒 + 铺底，基础层 |
| day.l2 | 同上 | 同上 | 固定种子 Karplus–Strong 拨弦分解和弦 |
| day.l3 | 同上 | 同上 | 柔和木笛对位 + 低声木质轻鼓 |
| night | 66 / 8 | 21.818182 s | 慢速八音盒摇篮曲 |
| memory | 60 / 8 | 24 s | 仅钢片琴，重复主题前两小节 |
| ending | 96 / 12 | 22.5 s | 三类声部齐奏，最终落回 G |

另外包含 8 条短乐句、30 条 SFX（含 D0 两条及低/中/高冰裂）、6 位说话音，以及 16 秒风和鸟鸣独立循环。旁白/笔记不制作说话音。小烬/阿暖/托比/米拉/老梅/大板牙的 ID 为 `talk.ember/anuan/toby/mira/mei/beavers`。
`music.preview.wav` 是可供用户试听的 12 秒片段拼接（标题 / 温暖全声部白天 / 结尾），**不是游戏正式循环曲**。

## 分层与峰值

三层均为 **360818 帧，22050 Hz，PCM16 单声道**；小节数一致，没有对单层做长度裁剪。
每层目标 RMS −21.8 dBFS（规范 −20±2 范围内）；不把各层分别推至满幅，更不把混合写入 Int16 使其溢出。
检查器以浮点相加检查 1/2/3 层，测试还穷举 7 种非空子集。

| 开启层数 | 混合峰值 dBFS | 混合 RMS dBFS |
|---:|---:|---:|
| 1 | −12.268941 | −21.800267 |
| 2 | −2.872132 | −18.852919 |
| 3 | −2.124543 | −16.842822 |

所有单文件 < 2 MB；全数 PCM16，音乐 22050 Hz，其余 44100 Hz。每个文件完整 SHA-256、峰值、RMS、帧数、接缝在 `export/manifest.json`。全局与单音边缘用平滑包络，不用硬剪裁/隐藏限幅补救错误编配。

## AudioService 接口与约束

- `play_music("music.day")`（或任一 `music.day.l*`）使用 Godot 原生 `AudioStreamSynchronized`，3 个流由同一个播放时钟从同一个起点启动；静音层持续走时，不在解锁时重新起播。
- `set_restored_count(n)`：0 处基础层，≥2 开拨弦，≥5 开木笛/轻鼓；1 秒增益渐变。支持减少计数与重复切换。
- 两个音乐槽在不同曲目之间 0.6 秒交叉淡化；相同曲目重复调用不重启。
- 首次鼠标点击（或显式 `unlock`）才启声；点击前音乐请求暂存。6 个轮转 SFX 槽，2 个嵌套环境播放器，不无限生成节点。
- `play_sound(id)` 与旧 `play_sfx(id)` 等价；`set_volumes(master,music,sfx)` / 旧 `set_volume(bus,linear)`，零音量明确 mute，恢复音量明确 unmute。Master 末端 −1 dB limiter 处理音乐+SFX 瞬时叠加；不代替离线混合峰值检查。
- `stop_all` 停所有流与 Tween，并清除曲目状态，允许再次播放同一曲。

## 验证边界

代码合成与双次逐样本确定性、保存字节比对、PCM 头/时长/响度/峰值/接缝和全部分层组合检查通过。D0 测试保留；D2 增加正式曲目/短乐句/SFX/六说话音覆盖。
**云端无音频输出设备，未主观试听；不把数值检查或播放器 playing 状态称作听感验收。** 用户可播放 preview WAV，后续仍需耳听循环自然度、音色、说话音和游戏内相对音量。

运行时回归脚本：`resources/audio/qa/runtime.gd`。从仓库根用 Godot 4.7.2 `--headless --path godot --script ../resources/audio/qa/runtime.gd` 运行（先同步；为 XDG_CONFIG_HOME / XDG_DATA_HOME / XDG_CACHE_HOME 指定可写缓存目录）。覆盖点击前静音/暂存、同步层、2/5 阈值、降低阈值、鸟鸣、重复曲目不重启、SFX 池、静音恢复、快速交叉淡化、全停后重播。

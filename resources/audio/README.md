# 声音制作源（D0）

全部由此目录的纯 TypeScript 合成器离线生成。没有录音、外部采样、生成模型或借用旋律。游戏只播放导出的 WAV；此目录不依赖 Godot 或游戏内容数据。

## 构建与验证

Node 22.13+，无 npm 依赖：

```sh
node --experimental-strip-types tools/resources/audio-pack.ts build
node --experimental-strip-types tools/resources/audio-pack.ts check
node --experimental-strip-types --test tests/audio.test.mjs
```

对应仓库命令 `npm run audio:build` / `npm run audio:check`。`check` 只读，不会用重新生成的文件覆盖错误产物。

- `cues/d0.ts` 是音符、音色和固定种子的唯一来源。
- `synth.ts` 的 `renderCue` 返回 PCM16；所有噪声由固定种子 PRNG 产生。
- `export/manifest.json` 为 `audio/1`，`assets` 中的 `file` 相对于此 `export/`；`hash` 为完整 WAV 的 SHA-256。清单没有时间戳或绝对路径。
- 数值验证包括双次逐字节比较、已保存产物比较、WAV 头、单声道 PCM16、采样率、长度、文件小于 2 MB、峰值 ≤ −1 dBFS、音乐 RMS −20 ±2 dBFS / 音效 −18 ±3 dBFS。
- 首尾样本必须为零，边界邻接样本幅度 ≤ 32 PCM 单位（约 −60 dBFS），避免只检验一个零点却留下突变；音符与整段都使用平滑边缘包络。分层曲目以后设置同一 `layerGroup`，检查器会核对采样率、帧数和循环模式。
- 不使用削波来强行满足响度；归一化后超峰值则报错，需要修改编配。

## 曲谱与音色

| id | 时长 | 采样率 | 设计 |
|---|---:|---:|---|
| `music.test` | 8 s | 22050 | D0 原创八音盒试奏，循环；不是最终标题曲 |
| `sfx.card_drop` | 0.24 s | 44100 | 两次错开的低音木质正弦敲击，混合低通种子噪声，像厚纸牌轻落木桌 |
| `sfx.ice_crack` | 0.48 s | 44100 | 三次错开的高通噪声与非整数倍共振，裂纹细密而不是爆炸；D2 再制作三档音高 |

### D0《春醒谣》试奏版本

3/4 拍，90 BPM，四小节；每个数字代表八分音符数量，每小节 6 个，共 24 个 = 8 秒。

```text
| G4×2 B4×1 A4×1 D5×2 |
| E5×2 D5×3 B4×1      |
| G4×3 A4×1 C5×2      |
| B4×2 A4×4           |
```

从 G4 向上探到 E5，再退回低处，最后停在 A4、不落回主音。相比文档示例的改写是为这段 8 秒管线试奏单独创作；保留“从低处向上爬、最后悬着”的轮廓，不替代 D2 的最终曲谱。音色为双算子 FM，快速柔和起音、慢衰减；单旋律，无和声及伴奏。没有引用任何外部作品。

## QA 记录与剩余范围

2026-10-26：三段通过自动数值检查及负面测试（损坏 WAV、静音、超峰值、非零接缝、错误采样率、无效音符）。PCM16 量化后的 RMS 约 −20.0003 / −18.0003 dBFS；完整精确结果与 SHA-256 见清单。

**听感尚未验收**：数值合格不代表好听；需要在 Godot 实际播放，确认木质落牌、温和冰裂、音乐重复时的呼吸感和相对音量后记录，不把自动检查冒称为听过。D2 的正式音乐、分层声部、全部音效与环境声尚未制作。Godot 导入应保持 PCM、音乐前向循环，运行时由 AudioService 控制音量与首次点击启声。
